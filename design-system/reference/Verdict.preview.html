Colour never carries a verdict alone: each state owns a glyph (filled, cross-filled, hollow) so it survives colour-blindness and the black-and-white printout of an audit bundle. No verdict renders without its evidence — an input count, a counterexample, or the exact reason for abstaining. Abstain is a true neutral, not a warning colour — it is an answer, not a fault.
